# 设置与音频设备

应用设置作用于所有工程；工程设置描述当前会话。各平台的兼容性矩阵请参阅
[支持的后端与插件格式](supported-backends.md)。

## 首次启动

首次启动时，选择浅色、深色或跟随系统的主题，以及 English 或简体中文界面。
主题与语言会立即预览。选择允许向 Sentry 发送崩溃报告后，点击**保存并重启**，
保存选择并重新启动 Heron；未开启时仍点击**继续**。保存失败时可重试，已选内容
不会丢失。如果重启被取消或失败，设置仍已保存，可以重试重启或稍后启动时生效。
欢迎设置只显示一次。已有安装升级到此
版本后也会显示一次欢迎设置。

崩溃报告可选，默认关闭。开启后重启 Heron 生效；关闭后立即停止新上传，
已经开始的上传可能继续完成。你可以随时在**系统设置 → 显示 → 常规**中更改。
报告包括 Electron 主进程错误和进程崩溃，也包括嵌入式原生音频 addon 导致的
崩溃。原生报告可能在下次启动时发送，可能包含文件路径和崩溃内存。撤回同意
期间的报告会被丢弃。不发送性能数据，也不将工程文件或录音作为附件上传。
开发和测试运行使用独立配置目录，不会上传报告，普通 CI 安装包也不会上传。
只有正式发布构建在获得同意后才会报告。

## 音频引擎

引擎页面控制隔离的原生音频服务如何运行。诊断实际生效的运行时配置时，
请以 Heron 显示的已解析值为准。

更改运行时选项后，请先让 Heron 重启音频辅助进程，再继续播放或录音。

## 音频设备

独立选择输入与输出设备，然后选择它们的通道配置与请求的缓冲区大小。

在以下情况下，Heron 仍能保持设备正常工作：

- 输入与输出使用不同的采样率；
- 设备使用独立的硬件时钟；
- 它们的缓冲区大小不同；
- 工程采样率与输出设备不同。

当自适应重采样、漂移校正或缓冲区回退生效时，应用会进行报告。这些是有用
的兼容机制，但让设备时钟与采样率保持一致，通常才是最简单的低延迟方案。

## 在没有音频硬件的情况下工作

后端列表的最后是**模拟**，它始终可用且无需驱动。它会正常运行引擎、走带、
混音台与插件，但从不打开真实设备：捕获是无声的，播放会被丢弃。

当没有连接音频接口、其他应用占用了设备，或你想在不发声的情况下编辑工程
时，可以用它继续工作。只有在无法连接任何其他后端时，Heron 才会自动选择
它。

模拟设备以 48 kHz 立体声运行，并将播放回环到捕获中，因此电平监测与往返
延迟测量仍会响应。需要听到会话时，请切换回硬件后端。

## 缓冲区大小

较小的缓冲区可降低监听延迟，但会增加截止时间压力。较大的缓冲区以延迟为
代价换取稳定性。

如果出现 XRUN：

1. 增大缓冲区；
2. 关闭占用 CPU 较高的应用；
3. 旁路开销较大的插件；
4. 查看性能监视器中的时序压力。

## 录音

录音设置控制软件监听、捕获格式，以及用于保存可恢复的未完成录音的交换
目录。请将交换目录放在剩余空间充足、写入性能可靠的驱动器上。

低延迟插件预算默认为 5 ms，可设置为 0–50 ms 的整数。拖动滑块时只更新本地
草稿，松开后最多发布一次音频图变更。预算只覆盖插件与 PDC 图延迟，不包含设备
buffer、ADC/DAC、采样率转换或输入 ring 延迟。它对实时路径的影响详见
[低延迟模式](low-latency-mode.md)。

## 显示

可选：

- 深色、浅色或跟随系统的颜色主题；
- English 或简体中文界面语言；
- 常规工作区外观选项；
- 混音台显示密度与行为。

显示与语言更改会立即生效，并保存在本机。

## 工程设置

打开**文件 → 工程设置**，编辑随工程保存的设置，包括工程名称、会话采样率、
音乐拍号与波形显示模式。

拍号分母选择器会有意只提供 1、2、4、8、16、32。当前不支持其他分母；关于
时序与 MIDI 兼容性的具体原因，请参阅[轨道与片段](tracks-and-clips.md)中的
**支持的拍号分母**。

更改会话采样率会改变工程时钟。当硬件以不同采样率运行时，Heron 会在
设备边界进行音频转换。
