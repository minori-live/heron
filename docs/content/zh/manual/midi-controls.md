# MIDI 控制

打开**设置 → MIDI → MIDI 控制**即可创建全局硬件映射。映射跨工程保留，控制器
断开时不会被删除；相同设备 ID 再次出现后会自动恢复。

## 学习控制器

1. 选择**学习 / 添加映射**。
2. 转动旋钮、编码器，或按下打击垫与琴键。第一个合法事件会写入设备、从 0
   开始的通道、消息类型与编号。
3. 选择输入模式和目标，然后选择**保存映射**。

学习期间已有映射暂停执行，原始值监视器仍持续更新。相对编码器还会显示解码
后的增量、事件速率与归一化增量。取消或离开页面都会结束学习。

新映射不会移除相同地址上的旧映射。一个地址绑定多个目标时会显示提示，但这
不是错误。每个目标独立、尽力执行：插件缺失不会阻止应用命令或混音台目标，
同一条 MIDI 消息也仍会送往乐器和录音。

## 输入模式

- **绝对值**把 0–127 的 CC 值交给绝对值变换预设。
- **相对值**必须明确选择 1/127、二进制补码或 binary offset；Heron 不会猜测。
- **音符**可触发应用命令以及 Mute/Solo toggle。

命令和 CC toggle 在值从 64 以下上升到 64 或以上时触发。绝对 Mute/Solo 以
0 表示关闭，非 0 表示开启。

## 目标

有序混音台目标采用 **Audio → Instrument → BUS → Master → Output**，同类别
再使用当前可见顺序。节拍器与系统通道不参与。重排会有意改变索引控制的通道。

插件映射使用工程内唯一的 control alias 与稳定参数 key。请先在同一设置页为
插件建立 alias。移动插件会保留 alias；删除插件只会让全局映射暂时无法解析。
只有可见、可写且可自动化的参数能够选择。

## 变换预设

Gain 默认使用 DAW 推子预设，Pan 与插件默认使用 Linear。内置预设只读；选择
一个绝对值预设可复制为用户预设，再通过可视化曲线与完全支持键盘的分段表格
编辑。预览会采样全部 128 个 CC 值。保存会同步更新所有引用，取消则丢弃草稿。

相对值预设由基础步长与基于事件速率的加速度组成。内置 Normal 不加速，Fine
提供更细的调整。

## 保存与 Undo

硬件调整会将工程标记为未保存，但不会写入 Undo。对同一混音台字段进行显式
鼠标编辑时，以该编辑为准。保存会在一个事务中提交混音台调整与捕获的插件
状态；保存失败会保留调整以便重试。选择不保存则丢弃。崩溃后不保证恢复尚未
显式保存的硬件调整。

Current 不包含 soft takeover、Mackie Control/HUI、硬件反馈、控制器显示屏或
Send 目标。
