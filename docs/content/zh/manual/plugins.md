# VST® 3 插件

[Plugin Analysis](plugin-analysis.md) 可在独立实验链中测量频响、相位、IR、泛音、
Hammerstein 模型和性能，并支持超过 0 dBFS 的浮点输入电平。

Heron 会从标准的系统与用户位置发现 VST 3 乐器与效果。插件运行在应用内嵌的
原生音频运行时中。加载失败会显示在界面上；严重的原生插件故障会终止应用。

当前不会扫描 Audio Unit、CLAP、VST 2 或 AAX 插件。完整的平台矩阵与计划
支持的格式请参阅[支持的后端与插件格式](supported-backends.md)。

## 扫描目录

Heron 会在启动时扫描。安装新插件后要重新查找：

1. 打开**资料库**；
2. 选择插件目录；
3. 选择**重新扫描 VST3**。

启动与扫描视图会报告发现的插件包、可用的插件，以及无法加载的模块。

首次加载插件前，Heron 会检查它支持的声道布局。如果一个插件包包含多个
插件，此次检查只针对你选择的插件。

## 添加乐器

添加一个乐器通道，然后选择其**乐器**输入槽。按名称或厂商搜索并选择插件。

如果乐器支持多种布局，请在加载前选择其音频模式。乐器模式包括单声道与
立体声输出。

## 添加效果

在任何兼容的混音台通道上：

1. 选择**音频效果**下的空槽位；
2. 搜索 VST 3 效果目录；
3. 选择一种受支持的模式；
4. 选择已加载的插入以打开其编辑器。

效果可能支持单声道、立体声、单声道转立体声或双单声道布局。不受支持的
模式在选择器中不可用。

## Heron EQ

**Heron EQ** 是内置效果器，每个实例最多支持 24 段。通过**音频效果**插槽
添加，然后打开原生编辑器。

图表是主要编辑区域。选中频段时，控件显示在图表下方中央；调整频率或增益时，
面板位置保持不变。单击图表空白处取消选择后，控件随即隐藏。
常用动作使用图标，悬停可查看提示。顶部栏提供 **⋯** 工具菜单；底部栏保留处理模式名称，频谱柱图标
打开分析器，扬声器旁显示输出百分比与 dB 读数。
活动图标高亮，不可用的动作变暗。

- 双击图表添加一段；拖动节点调整频率和增益，在节点上滚动鼠标滚轮调整 Q。
  右键节点打开操作菜单，可删除、复制或创建副本。Shift 单击可多选，
  从空白处拖动可框选多个节点。
- 选中频段的控件提供频率、增益与 Q 旋钮；双击旋钮或单击读数可输入精确
  数值。同一面板中可选择滤波器形状及 **Stereo**、**Left**、**Right**、
  **Mid** 或 **Side** 声道处理。Low Cut、High Cut 和 Band Pass 还提供以 dB/oct
  表示的滚降设置。电源图标可旁路或启用所选频段；耳机图标（**Solo focused band**）
  试听焦点频段，垃圾桶图标删除所选频段。
- 点击底部栏频谱柱图标打开 **Analyzer**，其中的 **Pre** 与 **Post** 显示实际测得的输入、输出频谱。
  频谱以平滑曲线呈现：Pre 为灰色细线，Post 为浅色填充曲线；右侧 dBFS 刻度
  表示频谱电平，左侧 dB 刻度表示 EQ 增益。
  **External** 显示当前插件已路由的侧链，编辑器只显示当前实例的频谱。
  雪花图标（**Freeze spectrum**）冻结频谱；**⋯** 中的键盘图标
  （**Piano / frequency snap**）将频率手势吸附到音符。

Heron 随工程保存和恢复 EQ 设置。撤销重做、预设管理与对比由宿主负责，EQ 编辑器不另设
本地历史、曲线绘制、A/B 或预设面板；频段使用静态滤波器。
要使用 [EQ Fit](plugin-analysis.md#拟合参数均衡器) 的结果，
请复制完整 JSON，添加新的空 **Zero latency** 实例，在顶部栏 **⋯** 菜单中选择
剪贴板图标（**Paste bands**）。这会添加拟合频段，并保留目标实例的处理模式与输出设置；
随后单独将输出增益设为拟合结果的**整体增益**。若结果不含频段，跳过粘贴，
只设置输出增益。频段传递不会导入整个预设。

各处理模式使用 Heron 自己的算法：**Zero latency** 使用数字滤波器，
**Natural phase** 使用过采样滤波，**Linear phase** 使用可选分辨率的对称 FIR。
宿主会补偿插件报告的延迟。若准备新处理器失败，
编辑器会提示错误，原处理器继续工作。

dB/oct 控件描述切除或带通滤波器的滚降。Bell 和搁架使用频率、增益与 Q，
不显示 dB/oct 数值。拟合的每段使用一个 RBJ 滤波节，并保留原始频率、增益与 Q。
这些数值及处理模式属于 Heron 的算法约定，仅照抄其他 EQ 的参数不保证得到
相同的频响。

频段选项菜单中的复制与剪贴板图标可在实例间传递频段。粘贴保留目标实例的
输出与处理模式，并且必须有足够的空闲槽位容纳所有复制的频段。

Analyzer 中的链环图标（**Fit EQ to sidechain spectrum**）将 EQ 拟合到当前实例的侧链频谱。
请先将参考音频路由到当前插件的侧链。

点击右下方扬声器与输出读数，可调整增益、自动增益、增益缩放、极性，以及 Left/Right 或
Mid/Side 声像。真正的单声道模式不应用声像。
输入输出电平表与峰值读数来自实际音频。
带斜线的扬声器图标（**Mute output**）将输出平滑降至真正的静音；全局旁路恢复经过延迟补偿的原始信号。
上下电平箭头（**Enable auto gain**）切换自动增益，带正负号的箭头
（**Invert output polarity**）切换极性反转。

## 管理插入

插入可以：

- 在其原生编辑器中打开；
- 旁路后再次启用；
- 移动到其他槽位；
- 移除；
- 切换到其他受支持的音频模式。

在支持撤销的操作中，更改或移除插件会记入工程历史。

## 路由侧链输入

当 VST3 乐器或效果实际提供单声道或立体声辅助音频输入时，其原生编辑器
工具栏会显示 **侧链**。打开菜单，先选择辅助输入总线，再从
**音频**、**乐器**或**辅助轨道**中选择来源通道。选择**无**可断开该输入；
每个辅助输入都可以独立配置。

来源固定取通道的 post-pan 信号，因此插件链、推子、静音、独奏与声像都会
影响侧链。不能直接选择硬件输入或内部总线；Master、输出、插件
自身所在通道，以及任何会形成反馈的来源也不会出现在可选项中。

工程变更提交期间会继续使用旧选择。提交失败时旧路由保持不变并显示警告。
如果工程已保存但音频图未能完整部署，则以新的工程值为准，同时在编辑器中
提示音频处于降级状态。

## 缺失或失败的插件

当存储的插件缺失、被隔离或无法启动时，工程会保持合法的信号路径。检查
槽位状态与目录状态，然后：

1. 确认安装了正确的插件与架构；
2. 重新扫描目录；
3. 如果插件是在宿主运行期间安装的，请重启 Heron；
4. 旁路或移除反复失败的插件。

永远不要假设名称或厂商相似的两个插件可以互换；它们的标识符与已保存
状态可能不同。
