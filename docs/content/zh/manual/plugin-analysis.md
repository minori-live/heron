# Plugin Analysis

选择 **帮助 → Plugin Analysis…**，打开独立分析窗口，无需先打开工程。
左侧使用与 Mixer 相同的插件选择器和槽位，可添加、排序、旁路、移除插件，
并打开原生或通用参数编辑器。实验链静音，修改不会影响工程。

左侧直接使用 Mixer 的 Audio FX 插入槽。点击第一个空槽，依次选择厂商、
效果和声道模式。**重新扫描** 会刷新内置插件及外部插件目录。
不可用的效果会显示加载／探测失败原因，不会被悄悄隐藏。

## 设置测量条件

在右上角 **测量设置** 中选择采样率、处理块大小、频率范围、扫频时长及稳定／尾音时长。
默认扫频 1 秒，稳定／尾音 0.25 秒。
**扫频输入电平**滑块支持 **−60 至 +12 dBFS peak**。0 dBFS 对应峰值 1.0，
+6 dBFS 的峰值约为 2.0。Heron 保留浮点幅度，便于测试 limiter 等效果器
超过满刻度时的行为，不会自动裁剪或归一化输入。

点击 **分析**。开启 **自动分析** 后，添加、移除、排序及旁路效果会立即排队重测。
参数、预置或测量设置修改停止后重测；电平滑块在松开时提交。
分析期间可以继续编辑；旧报告会标记为对应之前的状态。
**取消** 清除等待任务，并在处理块边界停止测量；正在执行的插件调用需要先返回。

## 阅读报告

将鼠标悬浮在曲线上，可查看曲线名称及当前单位下的测量坐标。
二维扫频频谱的悬浮提示显示测量时间、频率区间和峰值电平（dBFS）。
调整色阶范围只改变颜色，悬浮提示仍显示原始测量电平。

- **线性分析**：频响、相位及 IR。选择 L→L、L→R、R→L、R→R 查看各路径，
  使用主图下方的控制切换幅度、相位及 IR；**L + R** 同时显示两个直通声道。
  报告顶部的 **L/R–M/S** 开关会改变激励路由并折叠立体声输出，
  声道选择器随之显示 M/S。
  在图上从左上向右下框选可放大，从右下向左上拖动可缩小，
  从左下向右上拖动或双击可重置，滚轮平移、按住 Ctrl 滚轮缩放对应轴。
  **保留曲线** 可以叠加参考曲线，直到清除或切换响应视图。
  相位纵轴最小显示范围为 ±3°，避免浮点误差主导图形。
  可补偿实测延迟以比较相位。
- **泛音**：使用稳定正弦测量 H2–H8 的 dBc 和合计 THD。
  **二维扫频频谱** 使用真实输出：横轴为时间，纵轴为频率，颜色表示峰值频谱 dBFS。
  可以选择左右声道、linear／log 扫频及色阶范围。两种扫频分别测量，
  可观察整个输出频谱中的泛音和 aliasing 折返线。
  **一维泛音响应** 叠加 H2–H8；频率轴可切换 linear／log，幅度可切换基波百分比／dBc。
  **THD** 显示合计失真。切换视图使用已有报告，无需重新测量。
  超过 Nyquist 的阶次不参与统计，不会当成零。
- **Hammerstein**：各阶独立的 FIR 滤波器与直流偏置。可把多项式阶数设为 3 至 7，
  并使用独立信号验证模型预测与实测输出。拟合较差时高亮误差；
  **各阶响应** 叠加每一阶对滤波响应的贡献。压缩、调制和长尾效果
  往往需要更复杂的模型。
- **失真**：在可配置测试频率下测量单频 THD 与 THD+N，
  并测量固定 60 Hz 与 7 kHz 双音互调失真。
- **示波器**：采集正弦、方波、锯齿和三角波输出。
  **时域** 显示输出随时间变化并叠加输入；**波形整形** 显示输出对输入的关系，
  显示延迟默认使用插件报告的延迟。
- **动态**：**电平扫描** 将输入从 −100 扫到 0 dBFS，绘制峰值输出传递曲线并叠加 1:1 参考；
  **启动／释放** 输入三段电平并绘制输入／输出包络。
- **性能**：平均、P95、P99、最大处理耗时，音频预算占用、插件报告延迟及内存估算。
  使用所选处理块大小和插件的实时处理模式。

每份报告记录实际测量电平及条件。非线性效果的响应可能随电平和信号历史变化。
较大的重复差异或噪声底会降低频响和相位的可信度。
分析长延迟或混响时，可增加稳定／尾音时长。

内存变化属于 Electron 主进程，包括共享库和并行工作，无法精确归属到单个插件。
并行播放及系统负载也会影响耗时。

关闭窗口会释放效果链和编辑器，实验链及报告仅保留到窗口关闭。
如果无法确认资源释放，会话进入隔离状态，需要重启 Heron。

## 双链比较与测量控制

启用 **比较实验链**，在插槽上方选择实验链 1 或 2，分别编辑插件顺序、参数和旁通。
每条链最多容纳 16 个效果器。**1 | 2** 叠加两条链的曲线；**1 − 2** 实测两条链
音频输出的差值，保留相位与延迟差异，不自动对齐延迟。单链显示也用于选择二维频谱。
一轮比较的全部报告完成并释放测量实例后才一起显示。

测量设置新增 Sweep／Delta／Random（白噪声）激励、16384／32768／65536 FFT 大小，
以及实时、2×、4×、最高处理速度。不同激励对非线性效果器可能产生不同结果。
**循环测量** 重复完整分析；**取消** 同时停止循环和待处理测量。

失真页可切换 THD／IMD 输出频谱，检查噪声、泛音、混叠和互调边带。
泛音页新增 **基波增益** 曲线，显示稳定正弦扫频下基波的增益。
Hammerstein 使用每阶独立的 512 抽头 FIR 和直流偏置；静态视图使用各阶滤波器的直流增益，
各阶响应显示各自的真实滤波器频响。

动态测试可设置扫描起点、终点、步长、每档时长（0.4–1.5 秒），以及三段信号各自的
电平和时长（0.01–5 秒）。连续电平档位保留信号历史，应选择超过效果器启动时间的时长。
性能页新增 64、128、256、512、1024 采样处理块的平均与 P99 耗时曲线；速度限制等待
不计入回调耗时。
