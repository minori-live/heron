# Plugin Analysis

选择 **帮助 → Plugin Analysis…**，打开独立分析窗口，无需先打开工程。
左侧使用与 Mixer 相同的插件选择器和槽位，可添加、排序、旁路、移除插件，
并打开原生或通用参数编辑器。实验链静音，修改不会影响工程。

左侧直接使用 Mixer 的 Audio FX 插入槽。点击第一个空槽，依次选择厂商、
效果和声道模式。**重新扫描** 会刷新内置插件及外部插件目录。
不可用的效果会显示加载／探测失败原因，不会被悄悄隐藏。

## 设置测量条件

在右上角 **测量设置** 中选择采样率、处理块大小、频率范围、扫频时长及稳定／尾音时长。
默认扫频 1 秒，稳定／尾音 0.25 秒。
**扫频输入电平**滑块支持 **−60 至 +12 dBFS peak**。0 dBFS 对应峰值 1.0，
+6 dBFS 的峰值约为 2.0。Heron 保留浮点幅度，便于测试 limiter 等效果器
超过满刻度时的行为，不会自动裁剪或归一化输入。

点击 **分析**。开启 **自动分析** 后，添加、移除、排序及旁路效果会立即排队重测。
参数、预置或测量设置修改停止后重测；电平滑块在松开时提交。
分析期间可以继续编辑；旧报告会标记为对应之前的状态。
**取消** 清除等待任务，并在处理块边界停止测量；正在执行的插件调用需要先返回。

## 阅读报告

- **线性分析**：频响、相位及 IR。选择 L→L、L→R、R→L、R→R 查看各路径，
  使用主图下方的控制切换幅度、相位及 IR；**L + R** 同时显示两个直通声道。
  **保留曲线** 可以叠加参考曲线，直到清除或切换响应视图。
  相位纵轴最小显示范围为 ±3°，避免浮点误差主导图形。
  可补偿实测延迟以比较相位。
- **泛音**：使用稳定正弦测量 H2–H8 的 dBc 和合计 THD。
  **二维扫频频谱** 使用真实输出：横轴为时间，纵轴为频率，颜色表示峰值频谱 dBFS。
  可以选择左右声道、linear／log 扫频及色阶范围。两种扫频分别测量，
  可观察整个输出频谱中的泛音和 aliasing 折返线。
  **一维泛音响应** 叠加 H2–H8；频率轴可切换 linear／log，幅度可切换基波百分比／dBc。
  **THD** 显示合计失真。切换视图使用已有报告，无需重新测量。
  超过 Nyquist 的阶次不参与统计，不会当成零。
- **Hammerstein**：静态非线性后接线性 FIR 滤波。使用独立信号验证模型预测
  与实测输出。拟合较差时高亮误差；压缩、调制和长尾效果
  往往需要更复杂的模型。
- **性能**：平均、P95、P99、最大处理耗时，音频预算占用、插件报告延迟及内存估算。
  使用所选处理块大小和插件的实时处理模式。

每份报告记录实际测量电平及条件。非线性效果的响应可能随电平和信号历史变化。
较大的重复差异或噪声底会降低频响和相位的可信度。
分析长延迟或混响时，可增加稳定／尾音时长。

内存变化属于 Electron 主进程，包括共享库和并行工作，无法精确归属到单个插件。
并行播放及系统负载也会影响耗时。

关闭窗口会释放效果链和编辑器，实验链及报告仅保留到窗口关闭。
如果无法确认资源释放，会话进入隔离状态，需要重启 Heron。
