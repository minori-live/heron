# 插件手册

本手册介绍如何在支持相应插件格式的 DAW 中使用 Heron 插件。
选择下方的插件，了解它的控件与操作流程。

<PluginCompatibility locale="zh" />

## 开始使用

1. 根据操作系统与 DAW 支持的格式，[下载并安装插件](../releases.md)。
2. 重新启动 DAW，必要时重新扫描插件目录。
3. 在 DAW 中加载所需插件，并打开编辑器。
4. 保存 DAW 工程，以保留插件设置。

Heron Studio 已内置 Heron EQ，可直接加载，无需单独安装插件。

## 插件

- [Heron EQ](heron-eq.md) — 编辑 EQ 频段、观察频谱、匹配侧链参考，以及调整处理模式和输出设置。
