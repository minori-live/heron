# Heron EQ

Heron EQ 是一款最多支持 24 个频段的参数均衡器。本章介绍它在兼容的
VST® 3 或 Audio Unit 宿主中的操作。下载与安装请参阅[插件发布版本](../releases.md)，
功能概览请参阅 [Heron EQ](../heron-eq.md)。

![Heron EQ 的三个频段、频谱显示与所选频段控件](/plugins/heron-eq.png)

## 快速开始

1. 在 DAW 中将 **Heron EQ** 添加为音频效果，并打开编辑器。
2. 播放经过插件的音频。点击底部栏的频谱柱图标打开 **Analyzer**，
   启用 **Pre** 与 **Post**，查看输入和输出频谱。
3. 双击图表添加频段。水平拖动节点调整频率，垂直拖动调整增益，
   在节点上滚动鼠标滚轮调整 Q。
4. 选中频段，选择滤波器形状或输入精确数值。
5. 点击右下角的扬声器与读数调整输出，然后保存 DAW 工程以保留设置。

## 认识编辑器

频率图表是主要编辑区域。频率从左到右升高，左侧刻度表示以 dB 为单位的
EQ 增益，右侧刻度表示以 dBFS 为单位的频谱电平。EQ 响应曲线展示当前设置，
不断变化的频谱轨迹展示实际测得的音频。

选中频段后，控件出现在图表下方中央。拖动节点时，面板位置保持不变。
点击图表空白处可取消选择并隐藏频段控件。

顶部栏的 **⋯** 菜单打开 **Display & tools**。底部栏提供全局旁路、处理模式、
分析器与输出控件。将鼠标悬停在图标上可查看提示。活动控件高亮显示，
不可用的动作变暗。调整完成后，可用面板的关闭按钮将其收起。

## 添加与编辑频段

| 操作           | 方法                                      |
| -------------- | ----------------------------------------- |
| 添加频段       | 双击图表空白处。                          |
| 调整频率与增益 | 拖动频段节点。                            |
| 调整 Q         | 在节点上滚动鼠标滚轮，或使用 Q 控件。     |
| 输入精确数值   | 双击旋钮或点击读数，输入数值后按 Enter。  |
| 多选频段       | 按住 Shift 点击节点，或从空白处拖动框选。 |
| 移动一组频段   | 多选后拖动其中一个已选节点。              |
| 打开频段选项   | 右键节点，或点击所选频段的 **⋯** 按钮。   |
| 创建频段副本   | 在频段选项中选择 **Duplicate**。          |
| 删除频段       | 点击垃圾桶图标，删除所选频段。            |

**Frequency**、**Gain** 与 **Q** 分别控制所选频段的频率、增益与影响范围的宽窄。
频段控件中的电源图标可旁路或启用所选频段，并保留其设置。
耳机图标 **Solo focused band** 可试听焦点频段，再次点击即可退出独奏。

每个实例最多容纳 24 个频段，已旁路的频段也计入数量。达到上限后，
先删除不再需要的频段，再添加或创建副本。

### 选择滤波器形状

在所选频段控件的形状菜单中选择。

| 形状                       | 作用                               |
| -------------------------- | ---------------------------------- |
| **Bell**                   | 提升或衰减所选频率附近的一段频率。 |
| **Low shelf / High shelf** | 提升或衰减低频端或高频端。         |
| **Low cut / High cut**     | 切除所选截止频率以下或以上的频率。 |
| **Notch**                  | 衰减一个狭窄的频率区域。           |
| **Band pass**              | 保留一段频率，同时衰减两侧。       |
| **Tilt shelf / Flat tilt** | 改变低频与高频之间的平衡。         |
| **All pass**               | 调整相位，不以改变电平为目的。     |

**Low cut**、**High cut** 与 **Band pass** 提供以 **dB/oct** 表示的斜率设置。
斜率越陡，滚降越强。其他形状不显示此控件。
频段按你设置的参数处理声音，不会随输入电平自动改变增益。

## 选择频段处理的声道

使用形状控件旁的声道菜单。

| 声道             | 处理的信号           |
| ---------------- | -------------------- |
| **Stereo**       | 左右两个声道。       |
| **Left / Right** | 仅左声道或右声道。   |
| **Mid**          | 左右声道共有的成分。 |
| **Side**         | 左右声道的差异成分。 |

频段选项中的 **Split L/R** 与 **Split M/S** 可将所选立体声频段拆为独立的
Left/Right 或 Mid/Side 频段，以便分别调整。拆分需要在 24 段上限内留有足够空间。

**Display & tools** 中的 **Display channel** 只改变图表显示的声道，
不改变频段实际处理的声道。**Display range** 调整图表显示的 EQ 增益范围。

## 使用频谱分析器

点击底部栏的频谱柱图标打开 **Analyzer**。

- **Pre** 以灰色细线显示输入频谱。
- **Post** 以浅色填充轨迹显示输出频谱。
- **External** 显示路由到当前实例侧链输入的信号。

**Resolution** 调整频率细节，**Speed** 调整显示跟随变化的速度，
**Range** 调整可见电平范围，**Tilt** 调整频谱的显示倾斜度。
这些显示设置不会改变声音。显示倾斜度与显示声道也不会改变侧链匹配使用的原始测量结果。

### 冻结频谱

点击雪花图标 **Freeze spectrum** 保留当前捕获的频谱，再次点击恢复实时显示。
冻结频谱不会暂停音频或停止 EQ 处理。

### 将频率吸附到音符

打开顶部栏的 **⋯** 菜单，启用键盘图标 **Piano / frequency snap**。
此后调整频率的手势会吸附到音符。再次点击可恢复自由调整。

### 匹配侧链参考

1. 在 DAW 中将参考音频路由到当前 Heron EQ 实例的侧链输入。
   侧链路由通过宿主的控件设置。
2. 同时向主输入和侧链播放音频。在 Analyzer 中启用 **External**，
   确认插件已经收到参考信号。
3. 点击 Analyzer 中的链环图标 **Fit EQ to sidechain spectrum**。
4. 试听结果，并按需要调整频段或输出。

匹配根据主输入与侧链的实测频谱生成新的 EQ 设置。匹配成功后会替换当前频段、
处理模式与输出设置。如果需要保留原来的设置，请先在宿主中保存。
若频谱处于冻结状态，匹配会使用该次捕获；要使用新的测量结果，请先取消冻结。

匹配结果是固定的 EQ 设置，不会持续跟随参考音频的后续变化。
如果用于匹配的音频不足，可播放频率分布更广的素材后重试。
匹配失败时保留当前设置。点击关闭按钮或按 Escape 可收起结果提示。

## 复制与粘贴频段

1. 选中需要传递的频段。
2. 打开频段选项，选择 **Copy**。
3. 打开目标 Heron EQ 实例。
4. 在顶部栏 **⋯** 菜单中选择 **Paste bands**，或使用频段选项中的 **Paste**。

粘贴会追加复制的频段，并保留目标实例的已有频段、处理模式与输出设置。
目标必须有足够空位容纳全部复制的频段；无法完成粘贴时，目标保持不变。
频段复制粘贴只传递频段，不会导入完整插件预设。

编辑器获得键盘焦点时，Windows 与 Linux 的 **Ctrl+C / Ctrl+V / Ctrl+D**，
或 macOS 的 **Command+C / Command+V / Command+D**，分别用于复制、粘贴与创建频段副本。
**Delete** 或 **Backspace** 删除所选频段。

## 调整输出

点击右下角的扬声器与读数，打开 **Output**。

- **Output · dB** 设置输出增益。
- **Gain scale** 一起调整各频段增益变化的强度。
- **Enable auto gain** 的上下电平箭头切换自动增益补偿，帮助减小 EQ 带来的电平变化。
- **Pan** 根据所选模式调整 Left/Right 或 Mid/Side 平衡，在真正的单声道实例中保持中性。
- **Invert output polarity** 的正负号箭头反转输出极性。
- **Mute output** 的带斜线扬声器将输出静音，再次点击恢复声音。

输入输出电平表与峰值读数来自实际测量。底部栏的全局旁路恢复经过延迟补偿的
原始信号，可用于对比处理前后的声音。

## 选择处理模式

点击底部栏当前的模式名称。

| 模式              | 用途与控件                                                 |
| ----------------- | ---------------------------------------------------------- |
| **Zero latency**  | 不增加处理延迟，适合监听或实时演奏。                       |
| **Natural phase** | 提供另一种相位响应，会增加处理延迟。                       |
| **Linear phase**  | 线性相位 EQ，可选择 **Resolution**；分辨率越高，延迟越大。 |

Natural phase 与 Linear phase 会向宿主报告延迟，以便进行延迟补偿。
Linear phase 的分辨率可选 **Low**、**Medium**、**High**、**Very high** 与 **Maximum**。

当调整需要准备时，原有处理会继续运行，编辑器会显示当前状态。
如果准备失败，先前可用的设置继续生效。评估声音变化前，可先查看处理面板中的状态。

## 使用 MIDI 控制

先在宿主中将 MIDI 控制器消息路由到插件。选中一个频段，打开频段选项，
选择 **MIDI** 进入 **MIDI learn**。从列表选择要控制的参数，
再转动需要绑定的 MIDI CC 旋钮或移动推子。

**Clear band bindings** 清除焦点频段的绑定。
**Clear global bindings** 清除输出等全局控件的绑定。
这些绑定随插件状态保存。

## 保存与恢复设置

保存 DAW 工程可保留插件设置。要在其他工程中使用完整设置，使用宿主的插件预设功能。
撤销、重做与对比也通过宿主提供的相应控件完成。

编辑器的频段剪贴板用于传递频段。要恢复包含处理模式与输出设置的完整配置，
请使用宿主保存的插件状态或预设。
