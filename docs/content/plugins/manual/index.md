# Plug-in manual

Learn how to use Heron plug-ins in a DAW that supports their plug-in format.
Choose a plug-in below for its controls and workflow.

<PluginCompatibility />

## Get started

1. [Download and install the plug-ins](../releases.md) for your operating system
   and the format supported by your DAW.
2. Restart your DAW and rescan its plug-in catalog if needed.
3. Load the plug-in in your DAW and open its editor.
4. Save your DAW project to retain the plug-in settings.

Heron Studio includes Heron EQ, so it can be loaded there without a separate
plug-in installation.

## Plug-ins

- [Heron EQ](heron-eq.md) — Edit EQ bands, inspect spectra, match a sidechain
  reference, and adjust processing and output settings.
